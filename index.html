🤖 Rozpoznawanie AI przez zdjęcie — klucz Anthropic
Pobierz bezpłatny klucz na console.anthropic.com. Klucz jest przechowywany tylko lokalnie w tej przeglądarce — nigdy nie trafia do żadnego serwera zewnętrznego.
Jak działa: zrób zdjęcie czegokolwiek → Claude Vision rozpozna przedmiot → wypełni formularz → Ty akceptujesz.
Aby kamera skanera działała, plik musi być serwowany przez HTTP(S), nie z dysku (file://).

Opcja 1 — Python (zero konfiguracji):
cd /katalog/z/plikiem && python3 -m http.server 8080
Otwórz: http://localhost:8080

Opcja 2 — autostart przy logowaniu (Ubuntu/UDOO):
nano ~/.bashrc → dodaj na końcu:
cd ~/magazyn && python3 -m http.server 8080 &

Opcja 3 — Caddy (HTTPS z certyfikatem):
sudo apt install caddy
echo 'localhost { root * ~/magazyn; file_server }' > Caddyfile && caddy run

Czytnik USB/BT: Działa bez serwera — skaner emuluje klawiaturę, pole skanera w dialogu ma auto-focus.
